# Directory Overview

This directory contains a collection of Python scripts and Jupyter notebooks created for the purpose of learning the Python programming language. The files cover fundamental concepts such as variables, data structures (lists, dictionaries), conditional statements (`if`), and loops (`while`).

# Key Files

*   `variables_string.ipynb`: Jupyter notebook for learning about string variables.
*   `02_variables_List.ipynb`: Jupyter notebook for learning about list variables.
*   `03_variables_dict.ipynb`: Jupyter notebook for learning about dictionary variables.
*   `04_variables_bundles.ipynb`, `04_variables_bundles_more.ipynb`: Jupyter notebooks for learning about bundles.
*   `05_ifs.py`: Python script demonstrating the use of `if` statements for conditional logic.
*   `06_whiles.py`: Python script demonstrating the use of `while` loops.

# Usage

The files in this directory are intended to be used as educational material for learning Python. You can run the Python scripts directly from the terminal or interact with the Jupyter notebooks to explore the concepts in more detail.
